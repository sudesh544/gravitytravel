# GRAVITY Travel & Tourism Website

A responsive HTML/CSS/JavaScript travel agency website converted from the construction-style layout.

## Files
- index.html — complete page structure/content
- style.css — responsive styling
- script.js — mobile navigation, active navigation, form interaction
- logo.png — optional: place your final Gravity logo here

## Run
Open `index.html` in a browser.

## Customize first
1. Replace the contact details in `index.html`.
2. Replace the sample tour prices and package details.
3. Replace the Unsplash image URLs with your own optimized travel photos.
4. Connect the enquiry form to Formspree, EmailJS, PHP, WordPress, or your preferred backend.
5. If you have the Gravity logo PNG, place it in this folder and replace the text brand in the header/footer with `<img src="logo.png" ...>`.

## Notes
The current image URLs are remote demo images. For production, download/optimize your own licensed images and use local `/images/...` paths.
